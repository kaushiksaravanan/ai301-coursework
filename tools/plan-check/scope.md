# Scope: what this skill checks

## Repo

codepath/pathreview-ai301-fa26-s3

## What we grade

A plan comment posted on a GitHub issue. The plan describes:
- The root cause of the bug (diagnosis)
- What files will be changed (scope)
- How the fix will be tested (test plan)

## What we don't grade

- The code changes themselves (graded in Unit 4)
- Whether the fix actually works (graded when built and tested)
- The comment's tone or formatting (checked by voice-guide only)
- Issues or bugs not related to the claimed problem
